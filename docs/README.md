# GoldenSetDoctor Website

This folder contains the static GitHub Pages site for GoldenSetDoctor.

## Publish On GitHub Pages

After this branch is merged:

1. Open the repository on GitHub.
2. Go to **Settings**.
3. Open **Pages** in the left sidebar.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Set **Branch** to `main`.
6. Set the folder to `/docs`.
7. Save.

GitHub will publish the site at:

```text
https://sahil090192.github.io/GoldenSetDoctor/
```

The page is plain HTML/CSS/JavaScript and does not require a build step.
